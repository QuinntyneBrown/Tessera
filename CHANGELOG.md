# Changelog

This file records notable changes to Tessera. No version has been released.

## Unreleased

### Added

- High-level and detailed requirements for the SCORM player.
- Eight detailed feature designs with rendered architecture and behavior diagrams.
- A browser-based player UI mock.
- Contributor, support, security, conduct, and governance documentation.
- Issue and pull request templates.
- The MIT License.
- A demonstration .NET backend in `demo/video-stream-backend/` that streams a catalogued MP4 file to the video
  player as live fragmented MP4 over SignalR with MessagePack, with an xunit test project.

The requirements and designs describe planned behavior. They do not represent
a released or implemented SCORM player.
