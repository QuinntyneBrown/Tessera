# L1 - High-Level Requirements

## L1-001: Course loading
The player must accept either a SCORM ZIP package or an extracted course supplied by the host LMS, identify its version and course structure, and reject invalid or unsupported content with a clear explanation.

## L1-002: Course launch and navigation
The player must launch the course content selected by the learner and provide navigation that respects the course's structure and sequencing rules.

## L1-003: SCORM runtime compatibility
The player must provide the browser runtime communication required by SCORM 1.2 and SCORM 2004 2nd, 3rd, and 4th Editions, including their data models and error behavior.

## L1-004: Learner state and outcomes
The player must track and restore each learner's course state and report the course's progress, score, and completion outcomes accurately.

## L1-005: LMS integration
The player must exchange course state and outcomes with the host LMS through a documented integration boundary and report persistence failures.

## L1-006: Security and data protection
The player must protect learner data and the host application from untrusted course content, validate external input, and rely on the host LMS to establish learner identity and authorize course access.

## L1-007: Accessibility
The player controls and status information must conform to WCAG 2.2 AA, work by keyboard alone, and be usable with JAWS, NVDA, VoiceOver, TalkBack, and Narrator.

## L1-008: Responsive performance and reliability
The player must remain fully usable from extra-small to extra-large viewport sizes and at up to 400% browser zoom, meet defined performance targets, and present recoverable loading and failure states.
