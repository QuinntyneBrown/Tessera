Design system

Tessera design system

The visual and interaction language of Tessera's Learning Management System components: the SCORM player, the learner combobox and the live video player. Every value traces to the mocks or to a logged correction, both themes pass WCAG 2.2 AA, and every component works by keyboard and screen reader from 320px to 400% zoom.

How to use

  1. Link the CSS. tokens/tokens.css first, then assets/components.css. Do not link assets/ds.css in products; it styles these documentation pages only.
  2. Use the classes. Copy the markup from each page's Code section. States come from native attributes (disabled, aria-invalid, aria-pressed, aria-current, aria-busy); data-state is for documentation only.
  3. Theme with tokens. Set data-theme="light" or data-theme="dark" on any element, or leave it unset to follow the OS. Re-skin a component by overriding its component tokens (--btn-bg, --combobox-border, …), never by editing components.css.
  4. Consume tokens.json (DTCG format) to generate platform constants. Theme overrides are under $extensions.
  5. Shipped packages. @tessera/theme exposes the same decisions as --t-* properties; Theming maps one to the other.
  6. Check contrast after any colour change: check_contrast.py docs/design-system/tokens/tokens.css must pass in both themes.
