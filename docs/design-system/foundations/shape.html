Foundation

Shape

Corners grow with the element: small parts are nearly square, controls are softly rounded, cards and players are rounder, and pills are fully round. Edges are 1px, 2px for emphasis, and a 4px stripe marks status and the current lesson.

Overview

The mocks used seven radii (4, 6, 7, 8 and 12px, 50% and 999px); the system keeps five steps plus full and matches @tessera/theme's borderRadiusMedium (8px). Shape is the same in both themes.

The status stripe

A 4px inline-start stripe in the status solid colour marks a notice's kind without relying on its fill. The SCORM mock's notice and current lesson used 4px and the video error panel used 5px; all are now --border-width-stripe. It sits on the start edge, so it flips in right-to-left layouts.

Which radius for which size

The bigger the element, the bigger the corner. A nested element's radius is the parent's minus the padding between them, so inner corners never look fatter than outer ones.

Element sizeRadiusComponents
Tiny parts inside a control--radius-xs (2px)Focus inside tight controls, token swatches
Small, under 32px--radius-sm (4px)Chips, listbox options, checkboxes, tooltips, keycaps
Controls, 32 to 48px--radius-md (8px)Buttons, fields, selects, alerts and notices, menus, the combobox popup, video controls
Containers--radius-lg (12px)Cards, the outline panel, the SCORM player, the video player, dialogs
Full-width sheets--radius-xl (16px)Bottom-sheet dialogs on phones (top corners only)
Pills and circles--radius-fullBadges, avatars, the LIVE badge, "Go live" chip, big play button, lesson numbers, switches

Usage

  • Use --radius-full for circles too; 50% makes ellipses on non-square elements.
  • Edge-to-edge elements (banners, the top bar, a full-bleed video on phones) have no radius on the edges that touch the viewport.
  • Disabled controls keep their width and radius and switch the border to dashed; never thin the border to show disabled.
  • Use logical properties (border-inline-start) for the stripe so it mirrors in RTL.

Accessibility

  • Non-text contrast (WCAG 1.4.11): a control's 1px edge uses --color-border-strong, which passes 3:1. Radius never removes a visible edge.
  • Status is not stripe colour alone: the stripe is paired with an icon and a title, so it works for colour-blind learners and in forced colours (where it becomes a system-colour bar).
  • Invalid fields change both colour and width (1px to 2px), so the change is visible without colour vision.
  • Focus: the focus outline follows the element's radius in current browsers; no shape change is needed.
