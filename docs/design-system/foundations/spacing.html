Spacing

Every gap, margin and padding is a step on a 4px scale. Small steps hold a component together; large steps separate one component from the next.

4px base14 stepsrem-based

Overview

The token number is the multiple of 4px: --space-4 is 16px, --space-6 is 24px. --space-0-5 (2px) is the only half step, for hairline gaps between options and chips. Values are in rem, so spacing grows with the learner's text size and the layout keeps its proportions at 200% text.

The mocks already leaned on this grid (1rem, 1.5rem, 0.5rem, 0.75rem and 0.25rem are the five most used values) but also used 22 off-grid values such as 0.35rem and 1.3rem. Those were snapped; see snapped values.

Inside and between

Space inside a component is always smaller than the space between components, so the eye groups the right things. Components use --space-6 or less inside; layout uses --space-6 or more between.

Padding by component size

Padding steps with the control size so text never crowds the edge. Heights come from the interaction tokens (--control-height-sm/md/lg, 32 / 44 / 48px); the inline padding is spacing.

Usage

  • Use gap on the parent, not margins on children. .stack and .cluster take --stack-gap / --cluster-gap.
  • Use logical properties (padding-inline, margin-block) so right-to-left layouts mirror correctly, as the combobox mock's RTL toggle requires.
  • Page margins and grid gutters are layout tokens (--layout-margin, --layout-gutter) that alias spacing steps and grow with the viewport. Do not hard-code them per breakpoint.
  • Never write a raw length for spacing. If no step fits, the design is off-grid; pick the nearest step.
  • Negative space is still spacing: calc(-1 * var(--space-2)) pulls a dismiss button into a corner.

Accessibility

  • Targets: spacing never shrinks a target. Small controls (32px) keep at least --space-2 between neighbours so each still has a 24px clear area (WCAG 2.5.8).
  • Text spacing (WCAG 1.4.12): padding is set on min-height containers, so added line and paragraph spacing grows the box rather than clipping text.
  • Zoom: spacing is in rem, so 200% text keeps the same rhythm instead of crushing padding around larger letters.
