Foundation

Typography

One sans family, nine sizes and twelve named roles. Body text is 16px and never smaller than 12px anywhere; headings are bold and tight, reading text is relaxed and capped at a comfortable measure.

Overview

Type has two tiers. Primitives (--font-family-*, --font-size-*, --font-weight-*, --line-height-*, --letter-spacing-*) are the raw scale. Roles (--text-*) are complete font shorthands that components use: font: var(--text-label). A component that needs a different size keeps the role and overrides only font-size with another step, never a raw value.

  • Sizes are in rem, so browser text size and zoom scale everything together.
  • Headings and labels are bold (700); body is regular (400). The mocks' 750 renders as 700 in every fallback, so the system uses 700.
  • Page titles are tight (1.15) with negative tracking; body is 1.5; long-form and code are 1.6.

Measure

Reading text stops at 60 characters (--layout-measure, from the video mock's intro), so lines stay comfortable at every width and with 200% text. Lead paragraphs, page-header leads, empty-state bodies and alert bodies all cap at the measure; tables, forms and the player do not. The measure token belongs to layout.

Watch the session live from Lecture hall A. Captions are on by default. If the stream drops, the player reconnects on its own and keeps your place; you can return to live at any time.

Responsive type

  • The page title is 28px (--font-size-3xl) on phones and 32px (--font-size-4xl) from --layout-breakpoint-md (768px), via .page-header__title. This replaces the combobox mock's max-width: 40em override.
  • Everything else is fixed in rem. Body never shrinks on phones; 16px is already the floor.
  • Captions over video are the only fluid text: clamp(0.9rem, 2.2vw, 1.3rem) from the video mock, because they scale with the picture. They stay on the --text-body role.
  • Wrapping beats truncating: titles use text-wrap: balance; long course and learner names wrap (overflow-wrap: anywhere), never ellipsis, so nothing is lost at 400% zoom.

Usage

  • Use roles in components; reach for a size primitive only to step a role up or down (font: var(--text-label); font-size: var(--font-size-md) for field labels).
  • One h1 per page. Do not choose a heading level for its size; choose the level for the outline and the role for the look.
  • Sentence case everywhere. Uppercase only through --text-overline with wide tracking, and only for a few words.
  • Numbers that update (elapsed time, counts) use font-variant-numeric: tabular-nums so they do not jitter.
  • Never set text below --font-size-xs, and never in px.

Accessibility

  • Resize text (WCAG 1.4.4): all sizes are rem, and no container has a fixed height around text, so 200% text reflows without clipping.
  • Text spacing (WCAG 1.4.12): components survive line height 1.5, paragraph spacing 2em, letter spacing 0.12em and word spacing 0.16em, because heights are min-heights and rows wrap.
  • Reflow (WCAG 1.4.10): at 320px wide or 400% zoom, text wraps; there is no horizontal scrolling except inside data tables.
  • Contrast: muted and subtle text pass 4.5:1 on every surface, so small text never relies on the large-text 3:1 exception. See colour contrast.
  • Minimum size: 12px is used only for captions and badges, never for body copy, instructions or errors.
