Iconography

Icons in Tessera are simple line drawings that sit beside words, not instead of them. They inherit their colour and size from the text around them, and they are silent to screen readers unless they are the only thing naming a control.

Overview

Tessera ships no icon font and no sprite. Each icon is a small inline <svg> with the .icon class, so it scales with text, follows the theme through currentColor, and works in forced-colours mode without extra rules.

  • Line icons (the default) are drawn with a 2px stroke on a 24-unit grid.
  • Filled icons are reserved for media transport (play, pause, the speaker body, captions on), where a solid shape reads faster over moving video. Add .icon--fill.
  • The SCORM player mock uses no SVG icons: it writes "← Previous", "Next →" and a "✓" in the lesson number as text. The system replaces the arrows with the chevron icons below and keeps the check as an icon with aria-hidden="true".

Style

  • Grid: viewBox="0 0 24 24", with about 2 units of clear space on every side.
  • Stroke: 2 units, stroke-linecap: round, stroke-linejoin: round, no fill.
  • Colour: currentColor only. Never a fill or stroke value in the SVG.
  • Corners: round joins; rectangles use rx="2.5".
  • Filled media icons: solid shapes, no stroke (.icon--fill).
Line "retry" and filled "play", drawn at 4× on the 24-unit grid.

The .icon class in components.css carries the whole style, so the markup stays a bare path:

.icon { width: 1.25em; height: 1.25em; flex: none; fill: none;
        stroke: currentColor; stroke-width: 2;
        stroke-linecap: round; stroke-linejoin: round; }

Usage

  • Pair icons with words. An icon next to a label speeds up scanning; on its own it is a guess. Icon-only buttons are for controls that people already know (play, mute, close, fullscreen) or that sit in a labelled group.
  • One meaning per icon. "close" removes a chip and dismisses a dialog; it never means "clear the search". The combobox's "Clear all selections" is a text button for exactly that reason.
  • Direction: chevron-right trails "Next" and "Continue"; chevron-left leads "Previous". In right-to-left layouts mirror directional icons (chevrons, retry) with transform: scaleX(-1); never mirror media icons.
  • Colour comes from text. Set color on the parent (--color-danger-icon on an error, --color-fg-accent on an empty state); never set fill or stroke to a colour.
  • Status is never the icon alone. An error icon always has the error text beside it (WCAG 1.4.1).
  • Spacing: 4px (--space-1) to 8px (--space-2) between icon and label; buttons use their own gap.

Accessibility

Labelling

  • Decorative icons (beside a visible label, inside a status message, in an empty state): aria-hidden="true" focusable="false" on the <svg>. focusable="false" stops older Edge and IE builds from adding the SVG to the Tab order.
  • Icon-only buttons need aria-label with a verb and, where useful, the object: "Remove Ada Lovelace", "Show outline", "Pause". The SVG stays hidden. Show a tooltip with the same words on hover and focus.
  • Toggle icons change shape with state (mute and volume-off, captions-off and captions-on) but the name stays the same ("Mute", "Captions") and the state comes from aria-pressed. The video player names Play/Pause by the action it will take, so its label changes and it does not use aria-pressed.
  • Meaningful stand-alone icons (rare) use role="img" and aria-label on the SVG.
  • Never use <title> inside an SVG as the only name; support is inconsistent across screen readers.

Contrast

Icons that carry meaning need 3:1 against their background (WCAG 1.4.11). Because they use currentColor, they inherit the text colour, which already passes 4.5:1. The combobox toggle chevron uses --color-border-strong, which passes 3:1.

Forced colours and zoom

currentColor follows the system text colour in Windows contrast themes, so icons stay visible with no extra rules. Icons sized in em grow with 200% text; those sized in rem grow with the root font size.

Tokens

Iconography owns no tokens. Icons inherit their colour from the text colour of their parent (--color-fg-*, --color-*-icon, --color-media-fg) and their size from the font size (--font-size-*) through 1.25em; see colour and typography. Spacing beside a label uses --space-1 and --space-2.
