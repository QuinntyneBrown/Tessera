Slider

A slider sets a value where the rough position matters more than the exact number: playback volume, a passing score, how many days before a due date to remind learners.

WCAG 2.2 AAStatus: stableNative <input type="range">

Overview

Use a slider for a bounded numeric value that people adjust by feel and see the effect of straight away. Always show the current value next to it, and keep the range small enough that every step can be reached with the arrow keys in a reasonable number of presses.

  • An exact number (a score of 73, a time limit of 45 minutes): use a number text field, optionally beside the slider.
  • A few named levels ("Beginner", "Intermediate", "Advanced"): use a radio group or select.
  • A range with two ends (scores between 60 and 80): not supported; use two number fields. See Variants.
  • Playback position and media volume belong to the video player, which builds its volume control on this component.

Anatomy

  1. Label.field__label with for; names the value, not the control.
  2. TrackNative track; the filled part uses accent-color: --color-accent. The input row is 44px tall.
  3. ThumbNative thumb, also --color-accent. Drag, tap the track, or use the keys.
  4. Value label.slider__value (an <output>): bold 14px, tabular figures, at least 3ch wide so the row does not jump. Shows the same text as aria-valuetext.
  5. Ticks (optional).slider__ticks: 12px muted labels for the ends and meaningful midpoints, aria-hidden.

Variants

Single

Only where the effect itself shows the value (you hear the volume). Everywhere else add the value label.

With value label

3 days

Learners get one email this many days before the due date.

The value label and aria-valuetext carry units: "3 days", not "3"..slider__value
HTML
<div class="slider">
  <label class="field__label" for="lead">Reminder lead time</label>
  <div class="slider__row">
    <input type="range" id="lead" min="1" max="14" step="1" value="3"
           aria-valuetext="3 days before the due date" aria-describedby="lead-hint">
    <output class="slider__value" for="lead">3 days</output>
  </div>
  <p class="field__hint" id="lead-hint">Learners get one email this many days before the due date.</p>
</div>

Ticks label the ends and evenly spaced midpoints; they are a visual aid only, so they are hidden from assistive technology. Keep them to five or fewer..slider__ticks

Range (two thumbs): not supported

Two-thumb sliders are hard to operate by keyboard and screen reader, need custom ARIA, and have no native element. Use two labelled number fields instead; they are exact, validate clearly, and work everywhere.

Score band
Two number fields in .form__inline replace a range slider. Validate that the minimum is not above the maximum.

Sizes

One size. The input row is 44px tall (--control-height-md) and the native thumb follows the platform; the width follows the container (minimum 6rem).

States

The native control paints its own hover and pressed thumb; the system adds the amber focus ring (with a small radius) and keeps the label readable when disabled. Focus is forced here with data-state="focus".

  • Disabled uses the native disabled control; keep the label and value readable in --color-fg-disabled and say why next to it.
  • Invalid does not apply: the native range clamps to min, max and step, so the value is always valid. Validate combinations (minimum above maximum) on the number fields that replace a range slider.
  • Muted (video player): moving the volume to 0 sets Mute to pressed and announces "Muted."; raising it again announces "Unmuted, volume 40%."

Responsive behaviour

  • The range input fills the row (flex: 1 1 auto) with a 6rem minimum; the value label keeps its 3ch minimum so the track does not jump as digits change.
  • At 320px the slider takes the full column. If the value label and track no longer fit side by side at 200% text, the row wraps and the value moves below; nothing truncates.
  • Ticks space evenly across the width; drop midpoints and keep only the end labels when they would collide.
  • The video player hides its volume slider below --layout-breakpoint-md (48rem / 768px): on phones the hardware buttons set volume, and the Mute button and ↑ / ↓ shortcuts remain. General-purpose sliders are never hidden.
  • In right-to-left layouts the native range runs from right to left and the arrow keys follow the visual direction.

Theming

No component tokens: the native control is themed with accent-color: var(--color-accent), so the fill and thumb follow the accent in both themes (teal-600 light, teal-300 dark). The value label and ticks read --color-fg-default and --color-fg-muted. On media, the video player's volume uses --color-media-accent on the dark scrim instead. In forced-colours mode the browser draws the range in system colours.

/* Volume on the video player's scrim */
.media-player__volume { accent-color: var(--media-accent); }

See theming.

Accessibility

Role and pattern

Native <input type="range">, which exposes role="slider" with its value, minimum and maximum, following the WAI-ARIA APG Slider pattern. Set aria-valuetext whenever the number alone is not meaningful ("60%", "3 days before the due date") and update it on every input event, as the video player does for volume.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the slider.
→ / ↑Increases by one step (5 for volume and scores, 1 day for lead time).
← / ↓Decreases by one step. In RTL, ← increases.
Page Up / Page DownLarger jump (browser-defined, typically 10% of the range).
Home / EndMinimum / maximum.
Video player only: ↑ / ↓ anywhere in the playerChange the volume by 5. On the slider itself the native arrows apply and the player does not apply a second change.

Focus

The shared 3px amber ring with 2px offset and a --radius-sm corner surrounds the whole input on :focus-visible; on media it uses --color-media-focus-ring. Focus stays on the slider while the value changes.

Labelling

A visible <label for> names the value ("Passing score"); icon-only contexts such as the video control bar use aria-label="Volume". The <output for> value label is visible text, not the accessible value; aria-valuetext is. Hints are linked with aria-describedby. Ticks are aria-hidden.

The unfilled part of the native track is drawn by the browser and may fall below 3:1; the thumb, the fill and the visible value label carry the state, so the value is never conveyed by the empty track alone.

Motion

None. The thumb follows the pointer or key presses directly; there is no easing.

Touch

The input row is 44px tall, so the thumb and track are easy to hit. Dragging is never the only way (WCAG 2.5.7): tapping a point on the track moves the thumb there, and the keys and, where precision matters, a paired number field offer alternatives.

Content

  • The label names the value in sentence case: "Passing score", "Reminder lead time", "Volume".
  • Value labels and aria-valuetext include the unit: "80%", "3 days". Write the unit the same way in both.
  • Ticks label the ends first ("0%", "100%"), then meaningful midpoints; no more than five.
  • Use a hint for consequences: "Learners get one email this many days before the due date."
  • Choose a step people can reason about: 5 for percentages, 1 for days.

Sources

Extracted from these mocks:

  • video-player: the volume control is a native range (0–100, step 5, value 60) with aria-label="Volume" and aria-valuetext="60%" updated on every change; arrows move it by 5, ↑ / ↓ anywhere in the player do the same without double-applying on the slider; volume 0 mutes; it is hidden below 47.5em because the bar has no room and phones have hardware volume.

Drift fixed during extraction:

  • The volume's focus outline used a 4px corner and the media focus colour; the system keeps the shared 3px ring and 2px offset with --radius-sm (4px), and --color-media-focus-ring only on media.
  • The hide breakpoint was 47.5em written as max-width; it is now --layout-breakpoint-md (48rem), min-width first.
  • The 44px minimum height was written in px; it is now --control-height-md.
  • Value labels, ticks and the range alternative are derived: the mock shows volume without a visible value because the effect is audible.
