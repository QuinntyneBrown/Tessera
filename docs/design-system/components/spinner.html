Spinner

A spinner says "working on it" when the wait is short and its length is unknown: searching for learners, reconnecting to Lecture hall A. It always comes with words, visible or announced.

WCAG 2.2 AAStatus: stablerole="status" + visually hidden text

Overview

Use a spinner for waits of roughly 1–10 seconds where the amount of work is unknown and there is no layout to preview: results loading in the combobox, a stream reconnecting, an availability check on a field. Show it only after about 300 ms, so fast responses do not flash.

  • Use a progress bar when the amount of work is known, or the wait is long.
  • Use a skeleton when a page or card is loading and its layout is predictable.
  • For a button's own busy state, use the button's aria-busy="true", which draws the spinner for you.

Anatomy

  1. ArcThe top quarter of the ring in --color-accent; it is the moving part.
  2. TrackThe rest of the ring in --color-border-default; 2px (sm, md) or 4px (lg) wide, fully round.
  3. TextVisible ("Loading learners…") or visually hidden. Lives in the role="status" container; the ring itself is aria-hidden.

Variants

Standalone

The ring with hidden text, for places where the context already says what is loading (inside a field, centred in an empty list).

Loading learners
HTML
<span role="status">
  <span class="spinner" aria-hidden="true"></span>
  <span class="visually-hidden">Loading learners</span>
</span>

Inline with text

.loading-inline pairs the ring with muted text. Use it in status rows, under fields and in table footers. This is the combobox popup's status row: "Loading learners…".

Loading learners… Checking COM-204…
HTML
<span class="loading-inline" role="status">
  <span class="spinner spinner--sm" aria-hidden="true"></span>
  <span>Loading learners…</span>
</span>

In a field

The combobox shows a small spinner inside the field, before the toggle, while results load. It is decorative there (aria-hidden), because the combobox's own live region announces "Loading results." after 1 s and the listbox sets aria-busy.

Select one or more learners.

On media

.spinner--on-media swaps the colours for the media tokens so the ring reads on video. The video player's reconnecting state uses the large spinner with "Reconnecting… attempt 1 of 5" under it on a dimmed frame.

Reconnecting… attempt 1 of 5

The buffering state shows the same ring with no text; the player announces "Buffering" only if it lasts more than 1 s.
HTML
<div class="media-player__overlay media-player__overlay--dim">
  <div>
    <span class="spinner spinner--lg spinner--on-media" aria-hidden="true"></span>
    <p>Reconnecting… attempt 1 of 5</p>
  </div>
</div>
<!-- the player's polite live region says "Connection lost. Reconnecting." -->

States

A spinner is not interactive, so hover, focus, active and disabled do not apply. It has three lifecycle states: delayed (not shown for the first ~300 ms), spinning, and removed (replaced by the content, a result message, or an error). The matrix shows each size on each surface it supports.

  • Too long: after about 10 s, add text that sets expectations ("Still connecting…", as the video mock does at 5 s on a slow connection) or switch to a progress bar if the size becomes known.
  • Gave up: replace the spinner with an alert and a Retry ("Connection lost").

Responsive behaviour

  • Sizes are in rem, so the spinner scales with the user's font size and zoom; it does not change between breakpoints.
  • .loading-inline wraps its text next to the ring; at 320px the text wraps under nothing, the ring stays aligned to the first line's centre.
  • On media the large spinner stays 56px at every width; on very small players (under 240px tall) the text under it wraps rather than shrinking.

Theming

The spinner reads --color-accent (arc) and --color-border-default (track); on media --color-media-accent and --color-media-track. Size is the component token --spinner-size. In forced-colours mode the ring becomes ButtonText with a Highlight arc.

/* A 24px spinner for a one-off slot */
.course-tile .spinner { --spinner-size: 1.5rem; }

In the shipped packages the combobox spinner uses --t-combobox-border (from --t-colorNeutralStrokeAccessible) as a single-colour dashed ring, and the video player uses --t-video-player-accent; see theming.

Accessibility

Role and pattern

The spinner ring is aria-hidden="true". What it means is said by text inside a role="status" container (polite live region): visible text when there is room, or a .visually-hidden span ("Loading learners"). Insert the status container empty and fill it, or insert it after page load, so the text is announced. Where a component already owns a live region (combobox, video player), the spinner is purely visual and the component announces. The region being loaded sets aria-busy="true". See Understanding 4.1.3 Status Messages.

Keyboard

KeyAction
(none)Not focusable. If a wait can be cancelled, a Cancel button sits next to the spinner ("Loading course · Cancel" in the SCORM mock).

Focus

A spinner never takes focus. When it replaces a control the person activated, focus stays on that control (now busy); when the content arrives, focus is not moved unless the person asked for it (the combobox keeps focus in its input throughout).

Labelling

Text names what is loading: "Loading learners", "Reconnecting… attempt 1 of 5". Never "Loading" alone when more than one thing could be loading. Announce once at the start (after a short delay) and once at the end ("6 results available."); do not repeat while spinning.

Contrast

Arc on surface
Arc on canvas
Media arc on scrim
Inline text on surface
Media text on scrim

The track is decorative; only the arc must reach 3:1, and the text carries the meaning.

Motion

One revolution per --duration-loop-spin (900 ms), linear. Under prefers-reduced-motion the token becomes 2000 ms: the spinner slows to one revolution every 2 s rather than stopping, because a frozen ring looks like a hang and the motion carries status. It is a small, slow, non-flashing rotation (no WCAG 2.3 risk).

Touch

Not a target. A spinner never replaces a button's tappable area with something untappable; the busy button keeps its size.

Content

  • Name the thing and use an ellipsis: "Loading learners…", "Checking COM-204…", "Connecting…".
  • Add position when retrying: "Reconnecting… attempt 1 of 5".
  • After a long wait, reassure: "Still connecting…".
  • Announced text drops the ellipsis: "Loading learners".
