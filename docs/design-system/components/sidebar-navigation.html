Sidebar navigation

Sidebar navigation lists every destination in an area of the LMS, grouped under short headings, with the current page marked by the same inset accent stripe as the SCORM outline's current lesson.

WCAG 2.2 AAStatus: stableNative <nav> + <details>

Overview

Use sidebar navigation when an area has more destinations than fit in the top bar (more than six), or when they fall into groups: a course administrator's "Learning" and "Administration" sections, for example. Every item is a link that loads a page.

  • Grouped: links under non-interactive group headings. The default.
  • Collapsible groups: each group is a native <details>, so learners can fold away what they do not use. Use when there are more than about twelve links.
  • With badges: a count badge at the end of a link for things waiting ("3" assignments due).
  • Collapsed to icons: a 60px rail that keeps icons and hides labels visually. Opt-in, for wide layouts where the content needs the room.

Do not use it for steps in a sequence; the SCORM lesson list is a stepper because lessons have order, completion and locks. Do not use it to switch views of one object; use tabs. Do not put actions ("Create course") in it; actions are buttons in the page.

Anatomy

  1. Group heading.sidenav__heading (static) or a <summary> in .sidenav__group (collapsible): --text-overline, uppercase, muted.
  2. Current stripeInset 4px --color-accent (--border-width-stripe) on the start edge plus --color-accent-subtle fill, from the SCORM outline's current lesson.
  3. Icon (optional)1.25em, aria-hidden="true". Required in a sidebar that can collapse to icons.
  4. Label.sidenav__label: --text-label, bold 14px. Hidden visually (not from assistive technology) when collapsed.
  5. Badge (optional).badge.badge--count.sidenav__badge, pushed to the end. Carries a visually hidden noun ("3 due").

Sizes

Sidebar navigation has one density: 44px links (--control-height-md) in a 16rem column (--layout-sidebar-width), or a 60px rail when collapsed.

  • Current (aria-current="page"): accent-subtle fill, accent text and the inset 4px accent stripe on the start edge, exactly the SCORM outline's current lesson. Three cues, never colour alone; in forced-colours mode a 2px Highlight outline replaces them.
  • Active has no separate look; a link navigates on click and the next page shows it as current.
  • Disabled is not used. Remove destinations the person has no permission for; if a destination exists but is empty, link to its empty state.
  • Expanded comes from the native open attribute on <details>; the browser announces it.
  • Summary hover is shown with a token-only inline style; components.css has no hover rule for .sidenav__group > summary.

Responsive behaviour

  • At 64rem and wider (--layout-breakpoint-lg): the sidebar sits in its own 16rem column (--layout-sidebar-width) beside the content. Optionally collapsible to the 60px icon rail with a toggle button (aria-expanded) at the top of the rail.
  • Below 64rem: the sidebar leaves the layout and opens from the top bar's menu button as a full-width panel in DOM order after the header. The collapsed rail is never used on small screens, because icons alone are harder to learn on touch.
  • The SCORM mock's wrapping layout (.sidebar-layout) is the alternative for in-page side columns: the side column stacks above the main one whenever the main cannot keep 30rem, so enlarged text never squeezes it.
  • Labels wrap to a second line rather than truncating; with 200% text a link grows taller. Badges stay at the end and never overlap the label.
  • A long sidebar scrolls with the page; if it is sticky, it scrolls inside itself with overflow: auto and is never taller than the viewport.

Theming

The sidebar reads semantic tokens directly: --color-bg-surface (panel), --color-fg-default (labels), --color-fg-muted (headings), --color-bg-subtle (hover), and --color-accent-subtle + --color-fg-accent + --color-accent (current). It declares no component tokens; re-skin a host's sidebar by scoping semantic tokens.

/* A sidebar on a tinted canvas: lift the panel */
.lms-sidebar.sidenav { --color-bg-surface: var(--color-bg-surface-raised); }

In the dark theme the current fill becomes a deep teal and the stripe lightens with the accent; the label stays above 4.5:1. The shipped packages call the accent --t-colorBrandBackground and the current text --t-colorBrandForeground1; see theming.

Accessibility

Role and pattern

A <nav> landmark with a unique aria-label, containing lists of links. Collapsible groups use native <details>/<summary>, which matches the WAI-ARIA APG Disclosure pattern without ARIA. This is site navigation, not a tree: do not add role="tree" or role="menu"; see the APG disclosure navigation example.

Keyboard

KeyAction
Tab / Shift+TabMoves through group summaries and links in order. Links inside a closed group are skipped.
EnterOn a link: navigates. On a summary: opens or closes the group.
SpaceOn a summary: opens or closes the group. On a link: scrolls the page (browser default), as with any link.
EscWhen the sidebar is open as a panel on small screens: closes it and returns focus to the top bar's menu button.

Focus

The shared amber ring (3px, 2px offset) on links and summaries. After navigation focus starts at the top of the new page, where the skip link lets keyboard users jump past the sidebar. When the collapsed rail expands or collapses, focus stays on the toggle.

Labelling

The <nav> has a label that differs from the top bar's ("Course administration" vs "Primary"). Static group headings label their list with aria-labelledby. Icons are aria-hidden; in the collapsed rail the visually hidden .sidenav__label remains the link's name, so a screen reader still hears "Assignments, 3 due". Badges include their noun in hidden text. The current link is announced as "current page".

Motion

Groups open and close instantly (native <details>). If a host animates the rail width, it uses --duration-base, which prefers-reduced-motion zeroes.

Touch

Links are 44px tall. Group summaries are at least 24px tall (--target-min) with 8px padding and the full width of the panel, which meets WCAG 2.5.8; hosts with touch-first audiences can raise them to 44px. Nothing depends on hover: tooltips on the collapsed rail also show on focus, and the label is always in the accessible name.

Content

  • Link labels are nouns in sentence case that match the destination page's <h1>: "Assignments" leads to a page titled "Assignments".
  • Group headings are one or two words ("Learning", "Administration"); they are labels, not instructions.
  • Keep each group to seven links or fewer; split or rethink if it grows.
  • Badges show counts of things waiting for the person, up to "99+". Never use a badge for "New".
  • Order links by frequency of use, not alphabetically, and keep the same order on every page.
