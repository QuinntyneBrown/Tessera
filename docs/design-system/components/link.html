Link

Links move learners and administrators to another page, section or resource: the course outline, a SCORM reference, the player itself. They are always underlined, so they never depend on colour to be found.

Overview

Use a link when activating it only navigates: to another page, to a section of this page, or to a file. If it changes something (clears selections, retries a save, opens a dialog), it is a button, even when it should look like text; use .btn--link for that, as the combobox's "Clear all selections" does.

  • Inline (.link): inside a sentence, in body text size. "Read the content guidelines before you publish."
  • Standalone (.link .link--standalone): on its own line or at the end of a card, bold label, optional leading or trailing icon, at least 24px tall.
  • External: any link that leaves the LMS or opens a new tab. It shows an external icon and says "opens in new tab" to screen readers.

The skip link is a specialised link with its own page. Navigation links with a current page (aria-current="page") live in sidebar navigation, breadcrumb and pagination.

Anatomy

  1. LabelThe accessible name. --color-fg-link; inline links inherit the surrounding font, standalone links use --text-label.
  2. UnderlineAlways present, offset 0.15em. Thickens to 2px (--border-width-thick) on hover.
  3. Icon (optional)Standalone only. 1.25em, aria-hidden="true", 4px from the label. Arrow for "go to", external mark for new tab, download mark for files.

Choosing

  • Inside a sentence: inline. Never add an icon to an inline link except the external mark.
  • At the end of a card, under a notice, or as a list of related pages: standalone.
  • Leaving the LMS, opening a document viewer, or anything with target="_blank": external. Open a new tab only when leaving would lose the learner's place, such as a reference opened from inside a running SCORM lesson.

Sizes

Links inherit the size of the text they sit in; standalone links use --text-label (bold 14px). There is no size modifier.

States

Hover and focus are forced here with data-state. Visited links keep the link colour on purpose: learners revisit the same lessons constantly, and completion is shown by the outline's status, not by link colour.

Responsive behaviour

  • Inline links wrap with their sentence. Long URLs used as link text break anywhere (overflow-wrap: anywhere, as the SCORM mock's body sets) so they never force horizontal scroll at 320px; better still, never use a raw URL as link text.
  • Standalone links are at least 24px tall (--target-min). In a list of standalone links on phones, give each its own line with 8px between them so neighbouring targets do not overlap.
  • The trailing icon stays with the last word: keep the icon inside the link and avoid a space before it, so it never wraps alone onto a new line.
  • With 200% text and WCAG text spacing, the underline offset scales with the font (it is in em).

Theming

Links read --color-fg-link and --color-fg-link-hover. In the dark theme they lighten to --palette-teal-300 and --palette-teal-200, staying above 4.5:1 on dark surfaces. On an inverse or media surface, set color: inherit and rely on the underline, as the skip link does. In the shipped packages the link colour is --t-colorBrandForeground1; see theming.

/* A host LMS whose brand blue must be used for links */
.host-content .link { color: var(--color-info-fg); }
.host-content .link:hover { color: var(--color-fg-default); }

Accessibility

Role and pattern

A native <a href>, following the WAI-ARIA APG Link pattern. Never a <span> or <div> with a click handler, and never href="#" with script; if there is nowhere to go, it is a button.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to the next or previous link.
EnterFollows the link. Space scrolls the page; it does not follow a link.
Shift+F10 / context menu keyOpens the browser's link menu (open in new tab, copy address). Do not override it.

Focus

The shared 3px amber ring with 2px offset on :focus-visible. In-page links (#main, #player) must move focus to the target: give the target tabindex="-1" when it is not focusable, as both mocks do with their player regions.

Labelling

The link text is the accessible name and must make sense out of context ("View course outline", not "Click here" or "Read more"). External links add a visually hidden " (opens in new tab)"; downloads name the file type and size ("Course handbook (PDF, 2 MB)"). Do not use title for essential information.

Links are underlined, so they do not need 3:1 against surrounding text (1.4.1).

Motion

No animation. In-page links use smooth scrolling only when prefers-reduced-motion is not set.

Touch

Standalone links are at least 24px tall. Inline links are exempt from 2.5.8 because they sit in a sentence, but avoid putting two inline links next to each other with only a comma between them.

Content

  • Say where the link goes: "View course outline", "Open lesson 3: Give useful feedback", "SCORM 1.2 run-time reference".
  • Never "Click here", "Read more" or "Learn more" on their own; if a card needs "Read more", make the card title the link.
  • Sentence case; no trailing punctuation inside the link.
  • Do not use a URL as link text.
  • Put the link at the end of a sentence where possible, so the sentence reads well without it.
