Component · Navigation

Top bar

The top bar is the host LMS header that frames every Tessera surface: the product title on the left, primary navigation in the middle on wide screens, and a few page-wide actions on the right. Below 48rem the navigation folds behind a menu button.

Overview

Every mock opens with the same band: a 64px <header class="topbar"> with a bold 16px title ("Host LMS" in the SCORM mock, "Tessera · Host LMS" in the combobox and video mocks). The top bar belongs to the host LMS page, not to a Tessera component: the SCORM player, combobox and video player sit in the page below it and never draw their own header.

  • With title is the minimum: the product or LMS name, as in all three mocks.
  • With navigation adds three to six top-level destinations (Courses, Learners, Reports). Deeper structure belongs in sidebar navigation or tabs.
  • With actions adds at most three page-wide actions on the end side: help, notifications, the signed-in learner's account menu. Page-specific actions (Exit course, Preview assignment) stay in the page, not in the top bar.
  • Compact is not a separate component: it is how the same top bar renders below --layout-breakpoint-md (48rem). The navigation hides and a menu button with aria-expanded and aria-controls reveals it.

Do not use the top bar for a page title (use the page's <h1> under it), for step-by-step progress (use the stepper), or for a location trail (use the breadcrumb). See the navigation pattern for how the three fit together.

Anatomy

  1. Menu button (compact only).topbar__menu: a ghost icon button, 44px, aria-expanded + aria-controls. Shown below 48rem, hidden above.
  2. Title or brand.topbar__title (plain text) or .topbar__brand (a link home): --text-h4, bold 16px.
  3. Navigation (optional).topbar__nav: a labelled <nav> with a list of 44px links; the current one carries aria-current="page" and a 2px accent underline.
  4. Actions (optional).topbar__actions: up to three ghost buttons or a menu trigger, pushed to the end side with margin-inline-start: auto.
  5. Container.topbar: <header>, at least 64px (--layout-topbar-height), --layout-margin inline padding, surface background, 1px --color-border-default bottom edge.

Variants

Pick the smallest variant that serves the page. A Tessera component embedded in an LMS usually only needs the title; a full LMS shell adds navigation and actions.

Sizes

The top bar has one height: at least 64px (--layout-topbar-height), growing only when text is enlarged or wraps.

  • Current uses aria-current="page": accent text plus a 2px accent underline, so it never relies on colour alone.
  • Expanded: the menu button sets aria-expanded="true" and swaps its icon to a close cross; its accessible name stays "Open navigation" or changes to "Close navigation" (pick one approach and keep it on every page).
  • Disabled is not used for navigation: a destination the person cannot open is removed, not greyed out. Action buttons follow the button states.
  • Hover on nav links is shown with a token-only inline style because components.css has no data-state="hover" hook for .topbar__nav a.

Responsive behaviour

  • At 48rem and wider (--layout-breakpoint-md): navigation links show inline; .topbar__menu is hidden.
  • Below 48rem: .topbar__nav is hidden and .topbar__menu appears at the start. Activating it toggles aria-expanded and reveals the same links in a panel directly after the header in DOM order (a sidebar navigation list, full width), so focus moves forward naturally into the links.
  • The bar uses flex-wrap: wrap with a 12px row gap: at 320px, with 200% text or with WCAG text-spacing overrides the actions wrap to a second row instead of overflowing. The minimum height is 64px; the bar grows, it never clips.
  • Inline padding is --layout-margin, so it lines up with page content at every breakpoint (16px, 32px, 48px).
  • The top bar is not sticky by default. If a host makes it sticky, set scroll-padding-top to its height so focused elements are never hidden beneath it (WCAG 2.4.11).
  • Long titles wrap; they never truncate. Shorten the product name before shrinking the font.

Theming

The top bar reads semantic tokens directly: --color-bg-surface for the band, --color-border-default for the bottom edge, --color-fg-default for the title, --color-fg-muted for links and --color-fg-accent + --color-accent for the current link. It declares no component tokens of its own; a host re-skins it by scoping semantic tokens on the header.

/* An LMS with a branded band: scope the tokens, never edit .topbar */
.lms-header.topbar { --color-bg-surface: var(--color-accent-subtle); }

In the dark theme the surface becomes sage-900 and the current underline lightens with the accent, keeping both above their minimum contrast. In the shipped packages these are --t-colorNeutralBackground1, --t-colorNeutralStroke1 and --t-colorBrandForeground1; see theming.

Accessibility

Role and pattern

The container is a <header> directly under <body>, which exposes the banner landmark. Navigation is a <nav aria-label="Primary"> containing a list of links. The compact menu button follows the WAI-ARIA APG Disclosure pattern (aria-expanded + aria-controls), not the menu pattern: it reveals ordinary links. The account trigger opens a real menu and follows the Menu Button pattern.

Keyboard

KeyAction
Tab / Shift+TabMoves through skip link, menu button (compact), brand, navigation links and actions in visual order. No arrow-key roving: these are links, not a menubar.
EnterFollows a link; activates a button.
SpaceActivates the menu button or an action button.
EscWith the compact panel open and focus inside it or on the button: closes the panel and returns focus to the menu button.

Focus

The shared 3px amber ring with a 2px offset on :focus-visible. When the compact panel closes while focus is inside it, focus returns to the menu button; when the window widens past 48rem while the menu button has focus, focus moves to the current navigation link (the same rule the SCORM mock applies to its outline toggle), never to <body>.

Labelling

Every <nav> in a page has a distinct aria-label ("Primary", "Course outline"). The menu button is named "Open navigation"; its state is announced from aria-expanded, so the name does not need to say "open" or "closed" twice. Icon-only actions name their purpose and carry counts ("Notifications, 2 unread"). The current link is announced as "current page".

Motion

Nothing animates. The compact panel appears and disappears without a transition, so there is nothing to reduce under prefers-reduced-motion.

Touch

Navigation links, the menu button and actions are all 44px tall (--control-height-md) with at least 4px between them. Hover backgrounds are only applied under (hover: hover) in the related controls; nothing is reachable by hover alone.

Content

  • The title is the LMS or product name ("Host LMS", "Tessera · Host LMS"), not the page name. The page name is the page's <h1> ("Better conversations at work").
  • Navigation labels are one or two nouns in sentence case: "Courses", "Learners", "My assignments". No verbs, no "Go to".
  • Keep three to six navigation items. More than six belongs in a sidebar.
  • Icon-only actions need an accessible name and a tooltip with the same words.
  • Show the signed-in person's name ("Grace Hopper") next to the avatar on wide screens; on compact screens the avatar alone, with the name in the accessible label.

Drift fixed during extraction:

  • Title weight 750 (SCORM, video); normalised to 700 (--font-weight-bold) via --text-h4.
  • The combobox header had no minimum height (padding only); all three now use --layout-topbar-height (64px).
  • Gap 0.7rem and padding 1rem 1.5rem were off-grid or fixed; snapped to --space-3 and --layout-margin.
  • Container widths 1440px (SCORM, video) and 72rem (combobox) below the bar; unified on --layout-container-max.
