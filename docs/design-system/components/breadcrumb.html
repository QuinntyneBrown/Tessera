Breadcrumb

A breadcrumb shows where a page sits in the LMS hierarchy (Courses / Safety basics / Lesson 3) and lets a learner climb back up one or more levels.

WCAG 2.2 AAStatus: stableNative <nav> + <ol>

Overview

Use a breadcrumb on pages that are at least two levels deep in a strict hierarchy: a lesson inside a course inside the course catalogue, a learner's record inside an assignment. It sits above the page's <h1>, below the top bar.

  • Full: every ancestor as a link, then the current page as plain text with aria-current="page".
  • Collapsed to parent (.breadcrumb--collapse): the same markup; below 48rem only the parent link shows, prefixed with "‹". Use it on every breadcrumb that can be longer than three items.

Do not use a breadcrumb for history ("back to where I came from"); it shows hierarchy, not the path taken. Do not use it for steps in a process (use a stepper), or on top-level pages (Courses, Learners), where it would hold one item.

Anatomy

  1. Ancestor linkAn <a> in --color-fg-link, underlined, at least 24px tall (--target-min).
  2. Separator"/" drawn by CSS (li + li::before) in --color-fg-muted; not in the DOM, so screen readers do not read it.
  3. Current pagePlain text (not a link) with aria-current="page", bold --color-fg-default. Matches the page's <h1>.
  4. Container<nav class="breadcrumb" aria-label="Breadcrumb"> around an <ol>; --text-body-sm, wraps freely.

Sizes

Breadcrumbs have one size: --text-body-sm with 24px minimum link targets.

States

Ancestor links follow the link states. Hover and active are shown with a token-only inline colour because .breadcrumb a has no data-state hook; focus uses the shared hook.

  • Current: the last item is text, not a link, bold and in the default text colour, with aria-current="page". A link to the page you are on is a dead end.
  • Disabled is not used: every ancestor is reachable. If the person cannot open an ancestor (no permission), show it as plain text without a link.

Responsive behaviour

  • At 48rem and wider: the full trail shows and wraps onto more lines if needed; separators stay with the item that follows them.
  • Below 48rem with .breadcrumb--collapse: every item except the parent (li:nth-last-child(2)) is hidden and the parent gets a "‹" prefix, so the trail becomes a one-item "up" link.
  • Without the modifier the trail wraps; that is fine for two or three short items, which is why .breadcrumb--collapse is opt-in.
  • Long course titles wrap inside their item; they are never truncated with an ellipsis, so the full name is always readable at 200% text and with text-spacing overrides.

Theming

The breadcrumb reads semantic tokens directly: --color-fg-link (ancestors), --color-fg-link-hover, --color-fg-muted (separators) and --color-fg-default (current). It has no component tokens and no background; it inherits the surface it sits on.

/* A breadcrumb on a branded band */
.course-hero .breadcrumb { --color-fg-link: var(--color-fg-default); }

In the dark theme links lighten to a teal that stays above 4.5:1 on the canvas. See theming for the map to @tessera/theme.

Accessibility

Role and pattern

The WAI-ARIA APG Breadcrumb pattern: a <nav aria-label="Breadcrumb"> landmark containing an ordered list of links; the last item has aria-current="page". Separators are CSS-generated, so they are not announced.

Keyboard

KeyAction
Tab / Shift+TabMoves through the ancestor links in order. The current page is text and is skipped.
EnterFollows the link.

Focus

The shared 3px amber ring with a 2px offset on :focus-visible. Hidden items in the collapsed trail are display: none, so they leave the focus order too.

Labelling

The landmark is named "Breadcrumb"; screen readers announce "Breadcrumb, navigation, list, 3 items". Link text is the destination's title. In the collapsed trail the remaining link still reads "Safety basics"; the "‹" is decorative.

Motion

Nothing animates.

Touch

Links are at least 24px tall (--target-min), meeting WCAG 2.5.8; the separators add 4px either side, so adjacent links are never closer than the minimum spacing. On phones the collapsed trail leaves a single, easy target.

Content

  • Each item uses the destination page's title exactly: "Safety basics", not "Safety basics course".
  • The current item matches the page's <h1> ("Lesson 3: Fire exits").
  • Start at the highest meaningful level ("Courses"); do not start with "Home" when the top bar's brand already links home.
  • Sentence case; no trailing separator; no icons.
