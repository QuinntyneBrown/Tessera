Skip link

The skip link is the first thing a keyboard user reaches on every page. It stays out of sight until it receives focus, then appears in the top corner and jumps straight to the main content, past the top bar and navigation.

Overview

Every page that has a top bar, sidebar navigation or any repeated block before its content starts with a skip link. It is the first focusable element in the document, its target is the <main id="main"> landmark, and it is visible whenever it has focus. This page has one: reload and press Tab.

The skip link belongs to the host page, like the top bar. Tessera components never render their own; a host that embeds the SCORM or video player keeps one skip link to #main, and may add a second one to the player when the player is not the first thing in <main>.

Do not use the skip link as general in-page navigation (use headings and a table of contents), and do not hide it permanently for mouse users with display: none; it must stay focusable.

Anatomy

  1. Label--text-label, bold 14px, --color-fg-inverse, underlined as a link. Says where it goes.
  2. Container--color-bg-inverse fill, --radius-md corners, 12px × 16px padding (--space-3 / --space-4), 44px tall.
  3. Focus ringThe shared 3px amber ring with a 2px offset, drawn on the canvas around the dark fill.

Positioning: position: absolute at left: --space-4, parked at top: calc(-1 * --space-20) (above the viewport) and moved to top: --space-4 on :focus, with z-index: --z-tooltip so it sits over the sticky top bar.

Variants

There is one skip link look. Only the label and target change, for example a second "Skip to player" link on a page where the player is not first in main.

Sizes

The skip link has one size: --text-label with --space-3 by --space-4 padding, about 44px tall.

States

The skip link is invisible by default and only ever seen focused, so its states are shown with .skip-link--static (in normal flow, for documentation) and data-state. The demo links carry a token-only inline style: this documentation site's own stylesheet also defines .skip-link and would otherwise restyle them.

Both themes

Skip to content
Skip to content
  • Default: rendered, focusable and in the accessibility tree, but parked above the viewport. Never display: none, visibility: hidden or hidden.
  • Focus: slides to top: --space-4 with the amber ring. It stays visible for as long as it has focus.
  • Hover only happens while it is focused; the underline thickens, nothing else changes.
  • Disabled does not exist: a page without repeated blocks before <main> simply has the skip link land one element later.

Responsive behaviour

  • Identical at every width: 16px from the inline-start edge and top, sized by its text. At 320px and with 200% text the label wraps inside the box rather than overflowing.
  • In right-to-left pages it sits at the start edge (use inset-inline-start in hosts that support RTL).
  • It overlays the top bar instead of pushing content down, so focusing it never causes a layout shift.

Theming

The skip link reads --color-bg-inverse and --color-fg-inverse, so it is the highest-contrast object on the page in both themes: dark sage on a light page, light sage on a dark page. It has no component tokens; hosts should not re-skin it with the brand accent, because the amber focus ring must stay distinct from its fill.

The shipped packages do not render a skip link; hosts own it. See theming.

Accessibility

Role and pattern

A native same-page link, <a class="skip-link" href="#main">, first in <body>, satisfying WCAG 2.4.1 Bypass Blocks. The target is the <main id="main"> landmark, with tabindex="-1" so every browser moves focus (not just the scroll position) to it. There is no APG widget pattern; landmarks complement it (APG landmark regions).

Keyboard

KeyAction
Tab (first press on a page)Focuses the skip link and reveals it.
EnterMoves focus to #main; the next Tab continues from inside the main content.
Tab again (without activating)Hides the skip link and continues to the top bar as usual.

Focus

The shared 3px amber ring with a 2px offset; the offset sits on the page canvas, so the ring contrasts with the canvas, not with the dark fill. On activation focus moves to <main tabindex="-1">; main:focus shows no ring because :focus-visible is not triggered by script focus on a non-interactive element. A sticky top bar must not cover the target: set scroll-padding-top to its height.

Labelling

The link text is its name: "Skip to content". If a second skip link exists it names its target ("Skip to player"). Screen readers announce "Skip to content, link" first on every page; that consistency is the point.

Motion

It appears in place, with no transition. Nothing to reduce under prefers-reduced-motion.

Touch

Touch screen users without a keyboard never see it. With a keyboard attached to a tablet it behaves exactly as on desktop; its 44px height meets the comfortable target.

Content

  • "Skip to content" on every page. Same words, same place, every time.
  • A second link names its target: "Skip to player", "Skip to course outline".
  • Do not write "Skip navigation" (it says what is skipped, not where you land) or "Click here".

Sources

Extracted from these mocks:

  • scorm-player: <a class="skip-link" href="#player">Skip to player</a> targeting <main id="player" tabindex="-1">; ink fill, white text, parked at top: -5rem, shown at 1rem.
  • video-player: the same link targeting the player <div id="player" tabindex="-1">.
  • combobox: has no skip link (a gap, not a variant).

Drift fixed during extraction:

  • Targets differed (#player on <main> vs on a <div>) and the label named a component; unified on "Skip to content" → #main.
  • Padding 0.65rem 1rem was off-grid; snapped to --space-3 / --space-4.
  • z-index: 10 and top: -5rem were literals; replaced with --z-tooltip and --space-20.
  • --ink / white (SCORM) and --page-ink / --page-card (video) became --color-bg-inverse / --color-fg-inverse.
  • The page focus outline was 3px with a 3px offset; now the shared 3px ring with --focus-ring-offset (2px).
  • The combobox mock had no skip link; every page now has one.
