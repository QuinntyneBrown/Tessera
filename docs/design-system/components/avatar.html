Avatar

Avatars give a learner, presenter or course a recognisable mark next to its name: initials, a photo or an icon. They help people scan; the name beside them does the identifying.

WCAG 2.2 AAStatus: stableDecorative by default

Overview

Use an avatar beside a person's or course's name in lists, combobox options, table rows and headers. Do not use one on its own as the only way to identify someone; a name or accessible label always accompanies it.

  • Initials (default): one or two letters from the name, as in the combobox's custom option template ("AL" for Ada Lovelace).
  • Image: the person's uploaded photo, cropped to the shape. Falls back to initials when it fails to load.
  • Icon: a generic person or object icon when there is no name to take initials from (an anonymous viewer, a deleted account).
  • Square (.avatar--square): for things, not people: courses, sessions, groups. Taken from the combobox's course icon ("01" beside "Workplace safety essentials").
  • Group (.avatar-group): overlapping avatars with a "+n" overflow, for "who is assigned" summaries.
  • With status (.avatar__status): a dot for presence, such as "in the live session now".

Anatomy

  1. Container--avatar-size square, --radius-full (or --radius-md when square), --color-accent-subtle fill. Clips an image to its shape.
  2. ContentInitials in --text-overline (--text-label at lg), --color-fg-default; or an <img> with object-fit: cover; or a .icon.
  3. Status dot (optional).avatar__status: 30% of the size, bottom-right, --color-success-solid with a 2px --color-bg-surface ring so it reads over any picture.

Image

An image avatar is an <img> inside .avatar; the container crops it. When the avatar sits next to the name, the image is decorative: alt="". When it stands alone, alt is the person's name. If the image fails to load, swap in initials; never show a broken-image icon.

<span class="avatar"><img src="/learners/ada-lovelace.jpg" alt=""></span> Ada Lovelace
<span class="avatar avatar--lg"><img src="/learners/ada-lovelace.jpg" alt="Ada Lovelace"></span>

Sizes

AL AL AL 01 01 01
Small 24px (.avatar--sm) · medium 32px (default) · large 44px (.avatar--lg), round and square.
  • Small (24px): dense table rows and inline mentions. Initials drop to 10px; use small only where the avatar is decorative and the name is beside it.
  • Medium (32px): list items and combobox options (the mock's 2rem avatar).
  • Large (44px): headers, course marks (the mock's 2.75rem course icon) and avatars that are also a 44px button.

Responsive behaviour

  • Avatars never scale with the viewport; they use fixed rem sizes, so they grow with the user's text size and zoom like the names beside them.
  • Avatars never shrink in a flex row (flex: none); the name next to them wraps instead.
  • Groups show at most three or four avatars and a "+n"; at 320px reduce to two plus "+n" rather than wrapping the group onto two lines.
  • With 200% text the initials grow but the circle does not; keep two letters at most so they still fit.

Theming

The avatar has one component token, --avatar-size, and reads --color-accent-subtle (fill), --color-fg-default (initials and icon), --color-success-solid (status dot) and --color-bg-surface (the ring around dots and grouped avatars). Override the ring where avatars sit on another surface.

/* Avatars in a sunken panel: match the ring to the panel */
.side-panel .avatar-group .avatar,
.side-panel .avatar__status { box-shadow: 0 0 0 2px var(--color-bg-surface-sunken); }

/* A one-off 56px profile header */
.profile-header .avatar { --avatar-size: 3.5rem; }

In the dark theme the fill becomes sage-800 and initials sage-25. Do not colour avatars per person: hashed rainbow colours fail contrast in one theme or the other and suggest meaning that is not there. See theming.

Accessibility

Role and pattern

No widget pattern: an avatar is an image. Next to a visible name it is decorative (aria-hidden="true", or alt="" on an <img>). Alone, it is an image with the person's name (alt on <img>, or role="img" with aria-label on initials). A static group is one role="img" with a summary label; an interactive group is a list. When an avatar triggers a menu it is the content of a button following the APG Menu Button pattern; see WCAG 1.1.1 Non-text content.

Keyboard

KeyAction
TabPlain avatars are never focusable. An avatar button or "+n" button is one stop.
Enter, SpaceOn an avatar button: opens its menu or the full list of people.
EscCloses the menu or list and returns focus to the avatar button.

Focus

Only avatar buttons take focus; the shared amber ring goes around the button, not the circle, so it is never clipped by the round shape.

Labelling

Initials are never read on their own ("A L" means nothing). Groups say who and how many: "Assigned: Ada Lovelace, Grace Hopper, Alan Turing and 3 more". The "+n" button names what it reveals: "Show 3 more viewers". Status dots are aria-hidden; the status is in text beside the name or in the label ("Ada Lovelace, in session").

Contrast

Initials on avatar fill
Overflow "+n" on subtle fill
Status dot on surface
Status dot on avatar fill

The avatar fill itself has no contrast requirement against the page: it is decorative and the initials carry the content.

Motion

None. Image skeletons shimmer and stop under prefers-reduced-motion.

Touch

An avatar used as a control is wrapped in a 44px btn--icon, whatever the avatar's size. Plain avatars are not targets.

Content

  • Initials: first letter of the first two name parts, upper case ("Ada Lovelace" → "AL", "Katherine Johnson" → "KJ"); one letter for a single name. This is the combobox mock's initials() rule.
  • Square course marks use a short code or sequence ("01"), never a full word.
  • Overflow is "+" and a number ("+3"); its label is a sentence ("Show 3 more viewers").
  • Photos are of the person, cropped to the face; never use a placeholder stock photo.
