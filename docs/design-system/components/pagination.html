Pagination

Pagination splits a long list (learners, course completions, session attendance) into pages, says which page is showing and lets people move to the next, the previous or a specific page.

WCAG 2.2 AAStatus: stableNative <nav> + links

Overview

Use pagination under a table or list when the set is large, its order is stable, and people need to come back to a position or share it ("page 3 of the overdue learners"). Each page is addressable: page links carry the page in the URL.

  • Numbered: previous, page numbers, next. The default for tables of learners or results.
  • Simple: previous and next only, for short sets or when the total is unknown.
  • With summary (.pagination__summary): "Showing 21–30 of 248 learners" next to the controls. Add it whenever the total is known.
  • Gap (.pagination__gap): an ellipsis standing for skipped page numbers, when there are more than seven pages.

Do not paginate inside popups and pickers. The combobox pages its results with "Load more results" and by scrolling to the end of the list (six results per page in the mock), because a person searching wants to keep their place and their focus in the input. Use pagination for pages, "Load more" for lists inside a control.

Anatomy

  1. Previous / nextLinks named "Previous page" / "Next page"; an icon or the words. Disabled at the ends.
  2. Page link44 × 44px minimum, --text-label with tabular numbers, transparent until hovered. Named "Page 1".
  3. Gap.pagination__gap: "…" in --color-fg-muted, hidden from assistive technology.
  4. Current pagearia-current="page": accent fill, --color-fg-on-accent label.
  5. Summary (optional).pagination__summary: --text-body-sm, muted. Range and total with the noun.

Sizes

Pagination has one size: 44 × 44px targets (--control-height-md). Dense tables keep it; it is the main way to move through them.

  • Current (aria-current="page"): accent fill and border with --color-fg-on-accent; in forced-colours mode a 1px border keeps it distinct.
  • Disabled appears only on previous (first page) and next (last page): a dashed --color-border-strong edge and readable --color-fg-disabled text. For links, drop the href and add role="link" aria-disabled="true"; for buttons, use disabled. Keep it in place so the controls do not shift.
  • Loading: when the next page is fetched client-side, keep the controls and mark the results region aria-busy="true"; do not disable every page link.

Responsive behaviour

  • The list wraps (flex-wrap) rather than overflowing; with 200% text or at 400% zoom it may take two rows, never a horizontal scroll.
  • Below 40rem (--layout-breakpoint-sm): render first, current and last with gaps, plus previous and next (at most seven 44px slots, which fit 320px with 4px gaps). The summary moves above the controls.
  • The summary and the controls sit on one row when they fit and stack otherwise; the summary always comes first in DOM order.

Theming

Pagination reads semantic tokens directly: --color-fg-default (page numbers), --color-bg-subtle (hover), --color-accent + --color-fg-on-accent (current), --color-border-strong + --color-fg-disabled (disabled) and --color-fg-muted (gap and summary). There are no component tokens.

/* Quieter current page inside a card footer */
.card__footer .pagination { --color-accent: var(--color-accent-subtle); --color-fg-on-accent: var(--color-fg-accent); }

In the dark theme the accent lightens and the label flips to sage-900, staying above 8:1. See theming.

Accessibility

Role and pattern

A <nav> landmark with a specific label ("Learners pages") containing a list of links (server pages) or buttons (client-side pages). There is no APG widget pattern; it follows the APG landmark regions practice and uses aria-current="page" for the current page.

Keyboard

KeyAction
Tab / Shift+TabMoves through previous, page links and next. Gaps and disabled links (without href) are skipped.
EnterFollows a link or activates a button.
SpaceActivates a button (client-side pagination).

Focus

The shared 3px amber ring with a 2px offset. After a client-side page change, move focus to the results heading or table caption (with tabindex="-1") so the person starts reading the new page; the summary updates in place. After a full page load, focus starts at the top as usual.

Labelling

Name the landmark after what it pages ("Learners pages"), so it differs from other navigation. Number links are named "Page 3"; the current one is announced "Page 3, current page". Icon-only previous and next are named "Previous page" and "Next page". The gap is aria-hidden; the page names already convey the jump. Reference the summary with aria-describedby on the <nav>.

Motion

Nothing animates. When a client-side page change scrolls the results into view, it scrolls smoothly only without prefers-reduced-motion.

Touch

Every link and button is at least 44 × 44px with 4px between neighbours. Hover only applies under (hover: hover).

Content

  • Summary formula: "Showing first–last of total noun" ("Showing 21–30 of 248 learners"). Use an en dash for the range and group digits for totals above 9,999.
  • Visible previous/next text is "Previous" and "Next"; accessible names are "Previous page" and "Next page".
  • Keep page size stable (10, 25 or 50) and let the table offer a page-size select when people need it.
  • Do not show pagination for a single page; show the summary only ("8 learners").
