Component · Data display

List

Lists stack related items in one column: the lessons of a course, the learners on an assignment, the notes beside a live session. Each item reads on its own, with an optional picture, a title, a line of detail and a trailing value.

Overview

Use a list when items share a shape but not a set of columns to compare: lessons, learners, recent sessions, tips. Use a table when people compare the same attributes across items, a description list for the attributes of one item, and a menu for actions in a popup.

  • Simple: one line of text per item, such as the video player's "Try the interaction" notes.
  • Two-line: a title (.list__title) and a detail line (.list__meta), as in the SCORM course outline ("Ask better questions" / "Complete").
  • With avatar or icon: a leading avatar or icon tile, as in the combobox's custom option template (initials, name, e-mail).
  • Interactive: the whole item is one <a> or <button>. Use a link when it goes somewhere (a learner's profile), a button when it acts in place (open a lesson in the player).
  • Divided: .list--divided draws hairlines between items for long or dense lists.

Anatomy

  1. Item.list__item: flex row, --space-3 gap, --space-3 × --space-4 padding. As a link or button: at least 44px tall, --radius-md.
  2. Leading visual (optional)Avatar (initials or image) or a square icon tile. Decorative here: aria-hidden="true", because the title names the item.
  3. Title.list__title: --text-label at --font-size-md. The accessible name of an interactive item.
  4. Meta (optional).list__meta: --text-body-sm in --color-fg-muted. Status, detail or reason.
  5. Trail (optional).list__trail: pushed to the end; a value, a badge, a time or a chevron.

Sizes

One density. Items size to their content; interactive items are at least 44px tall (--control-height-md) and two-line items grow with their text.

  • Hover fills interactive items with --color-bg-subtle, only under (hover: hover). Static items have no hover.
  • Current (aria-current="true") marks where the person is: the activity playing in the SCORM player, the page being viewed. Fill --color-accent-subtle plus words in the meta ("Current activity"), so it never relies on colour.
  • Selected (aria-selected="true") is only valid on role="option" inside role="listbox"; use it when the list is a single- or multi-select picker, and add a check mark in the trail.
  • Disabled: keep the item focusable with aria-disabled="true" and put the reason in the meta, as the SCORM outline does for locked activities. Text stays readable in --color-fg-muted; a lock icon adds a non-colour cue. components.css has no .list__item[aria-disabled] rule yet, so the muted colour is set inline here.
  • Active has no separate look; activation moves focus or navigates.

Both themes

In the dark theme hover (--color-bg-subtle) and current (--color-accent-subtle) both resolve to sage-800, which is why current must also be said in words.

Responsive behaviour

  • Lists are one column at every width; they fill their container and never scroll sideways.
  • Titles and meta wrap; they never truncate in the list itself. .list__body has min-width: 0 so long e-mail addresses wrap instead of pushing the trail off screen; add overflow-wrap: anywhere for addresses.
  • At 320px or with 200% text the trail stays on the first line; when it holds a long badge, move it into the meta line instead.
  • In the SCORM layout the outline list sits beside the player and stacks above it when the player cannot keep 30rem (.sidebar-layout); below --layout-breakpoint-md it collapses behind a "Show outline" button.

Theming

The list reads semantic tokens directly: --color-fg-default (title), --color-fg-muted (meta and trail), --color-bg-subtle (hover), --color-accent-subtle (current and selected), --color-border-default (dividers). It has no component tokens; re-skin it by overriding those on a wrapper.

/* A course outline that marks the current activity more strongly */
.outline-panel .list__item[aria-current="true"] { box-shadow: inset var(--border-width-stripe) 0 0 var(--color-accent); }

The SCORM mock used exactly this inset 4px accent stripe on the current lesson; it is a host decision, not part of the base list. See theming.

Accessibility

Role and pattern

Native <ul> or <ol>; screen readers announce "list, 4 items". Interactive items are a single <a href> or <button> inside the <li>. Only when the list is a picker does it become a WAI-ARIA APG Listbox with role="listbox", role="option" and aria-selected. When CSS removes list markers, some browsers drop list semantics; the SCORM mock restores them with role="list" on the <ol>, and so should products.

Keyboard

KeyAction
Tab / Shift+TabLinks and button lists: each item is one stop, in order. aria-disabled items stay in the sequence so their reason can be read. Static lists have no stops.
EnterFollows a link item; activates a button item.
SpaceActivates a button item.
↑ ↓, Home EndListbox only: moves the active option (roving tabindex); the listbox is one Tab stop. Type-ahead jumps to an option by its first letters.
Space (listbox)Selects the focused option (multi-select: toggles it).

Focus

The shared amber ring (3px --color-focus-ring, 2px offset) on the whole item, so the target is obvious. When an action removes an item, focus moves to the next item, or the previous one if it was last, as combobox chips do.

Labelling

Name a list that stands alone with aria-label or aria-labelledby to its heading ("Course outline", "Assigned learners"). An interactive item's name is its title; its meta is linked with aria-describedby (the SCORM outline does exactly this: aria-labelledby title, aria-describedby detail). Avatars and icons next to the title are aria-hidden. Current is announced with aria-current and repeated in the meta text.

Motion

None. Hover fills change instantly; items added or removed do not animate.

Touch

Interactive items are at least 44px tall and full width, with no gap between them that could swallow a tap. Hover fills apply only under (hover: hover).

Content

  • Titles name the thing ("Ask better questions", "Ada Lovelace"), not the action ("Click to open").
  • Meta is one short line: a status, a detail or a reason. Separate parts with a middle dot: "Required learning · 35 minutes", "Current activity · Not reported".
  • Reasons for unavailable items say what unlocks them: "Locked until “Give useful feedback” is complete."
  • Trails are values, not sentences: "100%", "10:30", a badge.
  • Keep items parallel: all titles nouns, or all titles verbs, in sentence case.
