Select

A native drop-down for choosing one value from a known list: a theme, a preview scenario, a session room. The browser draws the list, so it works with every screen reader, keyboard and touch device without extra code.

Overview

Use a select when people choose exactly one value from a list you know in advance, with roughly 5 to 15 options. The mocks use it for the "Preview" and "Scenario" pickers (12 options) and the "Theme" picker (Light, Dark, System).

  • Two to four options that people should compare at a glance: use a radio group. On or off: use a switch or checkbox.
  • Many options, options from a server, search, or more than one choice (assigning learners to a course): use the combobox.
  • A list of actions rather than values: use a menu.

Tessera always uses the native <select>. A custom listbox is only justified when the native control cannot do the job (rich option content, multi-select); that is the combobox.

Anatomy

  1. LabelFrom the form field, above the control; beside it only in toolbars.
  2. Selected value16px --text-body, --color-fg-default. Never truncated by design: size the select to its longest option where space allows.
  3. ChevronDrawn in currentColor 16px from the end edge; the end padding is --space-10 so long values never run under it.
  4. Container44px (--control-height-md), 1px --color-border-strong, --radius-md, --color-bg-surface. Same box as the text field.

Variants

With a value

The video player mock's scenario picker. A sensible default is selected because every option is valid.
HTML
<div class="field">
  <label class="field__label" for="scenario">Scenario</label>
  <select class="select" id="scenario">
    <option value="live">Live</option>
    <option value="buffering">Buffering</option>
  </select>
</div>

With a placeholder option

Learners see the room in their calendar invite.

Use an empty first option when there is no safe default, so nobody submits a value they never chose.
HTML
<select class="select" id="room" required aria-describedby="room-hint">
  <option value="" selected>Choose a room</option>
  <option>Lecture hall A</option>
  …
</select>

Grouped options and inline label

<optgroup> labels are announced with each option. Inline labels, as in the mocks' state panels, are for toolbars only; the select then sizes to its content.

Sizes

Match the size of the text fields and buttons beside it. Medium is the default for forms; small for dense filter bars above a table (still above the 24px minimum); large next to a large search.

Heights --control-height-sm/md/lg; text --text-body-sm / --text-body / --text-body-lg.
HTML
<select class="select select--sm">…</select>
<select class="select">…</select>
<select class="select select--lg">…</select>

Pointer and focus states are forced with data-state; "Active" is the open list, drawn by the browser and operating system, so it is shown here as focus. Matrix selects use aria-label to keep the table compact.

Choose a room for the session.

  • Invalid only appears with a placeholder option, when nothing was chosen; the form field adds the icon and message ("Choose a room for the session.").
  • Disabled dashes the edge and keeps the value readable. There is no read-only select in HTML; show an unchangeable value as text or a read-only text field.
  • The open list is native: its colours follow color-scheme (set by the theme), so it is dark in the dark theme without extra CSS.

Responsive behaviour

  • Full width of its field by default, so a long value never overflows at 320px; in toolbars it may size to content (width: auto) but keeps max-width: 100% and wraps to its own line with its label, as the mocks' state panels do.
  • On phones the operating system shows its own picker (a wheel or sheet), which is large, scrollable and accessible; nothing in Tessera needs to change for touch.
  • At 200% text the select grows taller; long values are clipped by the browser inside the box, so keep option text short.
  • In right-to-left layouts the chevron should sit on the left; the current chevron is positioned from the right edge, so RTL forms need the logical-position fix noted in the sources.

Theming

The select shares --field-bg, --field-fg, --field-border and --field-height with the text field. The chevron is two gradients in currentColor, so it follows --field-fg and turns --color-fg-disabled when disabled. The native list follows color-scheme, which each theme sets.

/* A compact filter bar sets the size once for all its selects */
.learner-filters .select { --field-height: var(--control-height-sm); }

Shipped equivalents: --t-colorNeutralBackground1, --t-colorNeutralForeground1, --t-colorNeutralStrokeAccessible. See theming.

Accessibility

Role and pattern

Native <select>, exposed as a combobox (collapsed) with a listbox of options. The browser implements the interaction that the APG select-only combobox example rebuilds in script; Tessera does not rebuild it. Changing the value never submits or navigates by itself (on input).

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the select. Disabled selects are skipped.
Space, Enter, Alt+↓Opens the list (exact keys vary by platform).
↑ / ↓Moves through options; on Windows this changes the value without opening the list.
Home / EndFirst or last option.
Typing lettersType-ahead: jumps to the next option starting with the typed text ("Le" to "Lecture hall A").
Enter (open)Chooses the highlighted option and closes the list.
Esc (open)Closes the list without changing the value.

Focus

The shared ring (3px --color-focus-ring, 2px offset) on :focus-visible. Focus stays on the select while the list is open and returns to it on close.

Labelling

  • A visible <label for>. The placeholder option ("Choose a room") is not a label; it is announced as the value.
  • required on the select; "(required)" in the label; aria-invalid and aria-describedby for errors.
  • <optgroup label> names groups; screen readers announce the group with the option.

In forced-colours mode browsers drop gradient backgrounds, so the drawn chevron disappears; the select is still identified by its system border and role.

Motion

Only the border colour transitions (--duration-fast, zeroed under reduced motion). The native list opens without Tessera animation.

Touch

Medium (44px) and large (48px) meet the comfortable target; small (32px) exceeds the 24px minimum and is only for pointer-first filter bars. Touch devices use the native picker, which has its own large targets.

Content

  • Label names the setting: "Theme", "Room", "Sort learners". Not "Select a theme".
  • Placeholder option starts with a verb: "Choose a room". Only use one when there is no safe default.
  • Options are short, parallel and in sentence case: "Light", "Dark", "System". Order them logically (by frequency, sequence or alphabet), and say which in a hint if it is not obvious.
  • Put qualifiers in brackets after the main word so type-ahead still works: "Connecting (slow)", "Reconnecting (gives up)".
  • Errors say what to choose: "Choose a room for the session."

Sources

Extracted from these mocks:

  • combobox: "Preview" (12 scenarios) and "Theme" (Light, Dark, System) selects in the "Mock states" panel, with labels beside them and a Reset button.
  • video-player: "Scenario" (12 options) and "Theme" selects, 44px minimum height to match the Reset button.
  • scorm-player: its "Mock states" panel uses buttons only ("Show loading", "Fail next save"); it contributes the panel layout and the 44px row height, not a select.

Drift fixed during extraction:

  • Radius 0.375rem (6px, combobox) and 7px (video) snapped to --radius-md (8px).
  • Combobox select height came from 0.5rem padding (about 38px) beside 44px buttons; unified on --control-height-md.
  • Video padding 0.45rem / 0.7rem was off-grid; snapped to --space-2 / --space-3.
  • Panel text 0.85rem snapped to --font-size-sm for inline labels; form selects use 16px values.
  • The native arrow differed by browser; replaced by one drawn chevron in currentColor. Open issue: it is positioned from the right edge and vanishes in forced colours; a logical-position, forced-colours-safe chevron is needed in components.css.
