Empty state

An empty state fills a region that has nothing to show yet, or nothing that matches. It says what happened and what to do next, so an empty list never looks like a broken one.

Overview

Use an empty state inside a region (a list, a table, a panel, a popup, the video stage) when the region loaded successfully but has no items to show. There are four reasons a region is empty, and each gets its own copy:

  • First run: nothing has been created yet ("No assignments yet").
  • No results: a search or filter matched nothing ("No learners match “Hoper”").
  • No permission: content exists but this person cannot see it.
  • Error as empty: the region could not load and has nothing to fall back on ("Learners could not be loaded").

A finished session is a fifth, media-specific case: the video player's ended card ("Session ended · Live for 00:48:12") replaces the picture once a stream is over.

Use an error page when the whole page cannot be shown, an alert when content is still shown but something is wrong, and a skeleton or spinner while content is still loading. Never show an empty state before loading has finished. See the empty and error states pattern.

Anatomy

  1. Icon48px circle (32px compact) in --color-accent-subtle with a 24px line icon; aria-hidden. No illustrations: they add weight without meaning.
  2. Title--text-h3 (18px bold; --text-h4 compact). What happened. A heading at the right level in product.
  3. BodyMuted, one sentence: what to do next, or why.
  4. Actions (optional)One primary action that resolves the emptiness, and optionally one link for help. Centred in full, start-aligned in compact.

Sizes

Full (default) is centred, up to 28rem wide, with 48px block padding; use it when the empty region is the main content of a page or panel. Compact (.empty-state--compact) is a start-aligned row with a 32px icon and 16px padding; use it inside popups, table bodies, sidebars and cards.

No results

Try a different name or email.

  • Appearing: only after loading completes. In the combobox, "No results" replaces "Loading learners…" in the status row and "No results found." is announced.
  • Resolved: when the person acts (clears the search, creates the first item), the empty state is replaced by content; focus goes to the new item or stays on the control that was used.

Responsive behaviour

  • Full empty states centre within their region and cap at 28rem; on phones they keep 24px inline padding and actions wrap, centred.
  • Compact empty states stay a row (icon + text) down to 320px; the text wraps beside the icon.
  • Use compact automatically inside containers narrower than about 20rem (popups, sidebars), even when the content type would normally get full.
  • On the video stage the ended card centres over the picture and wraps its text; at 320px the card's padding stays 20 × 24px.

Theming

The empty state reads --color-accent-subtle and --color-fg-accent (icon), --color-fg-default (title) and --color-fg-muted (body); the danger variant swaps the icon to --color-danger-bg / --color-danger-icon. The ended card reads --color-media-scrim and --color-media-fg, the same in both themes. There are no component tokens; re-skin by overriding semantic tokens on a wrapper. See theming.

Accessibility

Role and pattern

Plain content: a heading, a paragraph and native buttons or links; no ARIA role. When an empty state replaces results after a search, announce it through the component's existing polite live region ("No results found.") rather than giving the empty state its own role. In a combobox the message lives in the popup's status row, outside the listbox, so the listbox never contains a fake option. See Understanding 4.1.3 Status Messages.

Keyboard

KeyAction
Tab / Shift+TabReaches the action and help link in order. The icon, title and body are not tab stops.
Enter, SpaceActivates the action.
EscIn a combobox popup, closes the popup (then clears the query), as with results.

Focus

Showing an empty state does not move focus, so a person typing in a search keeps their place. The exception is the media ended card: if focus was inside the player, focus moves to its heading (tabindex="-1") because the controls it was on are now disabled.

Labelling

The title is a heading so the empty region is findable by heading navigation. The icon is aria-hidden. Actions name their result ("Clear search", "Assign course").

  • Be specific: echo the query in curly quotes; name the course or team.
  • Don't blame ("You have no…" is fine; "You didn't…" is not) and don't joke; an empty assignment list can mean missed training.
  • One sentence of body text. If you need more, link to help.
  • Keep "No results" as a short fallback where space is tight (combobox status row), but prefer the guiding version.
