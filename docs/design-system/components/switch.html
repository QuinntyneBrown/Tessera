Switch

A switch turns one setting on or off and the change takes effect at once: email reminders, the transcript panel, quiz retakes.

WCAG 2.2 AAStatus: stable<input type="checkbox" role="switch">Derived

Overview

Use a switch for a setting that is either on or off and applies immediately, without a Save button: a preferences page, a course settings panel. Confirm the change with the switch's own state, and with a status message if it affects other people.

  • Part of a form that is submitted later: use a checkbox. A switch that waits for Save misleads.
  • A choice between two named options ("In person" / "Online"): use a radio group.
  • A toggle inside a toolbar or control bar: use a pressed button (aria-pressed). The video player's Captions control is a pressed button, not a switch, because it sits in a toolbar-like group of buttons (Play, Mute, Captions, Fullscreen) where every control is a button and has a one-key shortcut; a switch there would break the group's consistent model.

Anatomy

  1. Track44 × 24px, --radius-full, 2px --color-border-strong edge; fills with --color-accent when on.
  2. Thumb16px circle; --color-border-strong at the start when off, --color-fg-on-accent at the end when on. Position is the non-colour cue.
  3. LabelBody 16px; names the setting. The wrapping <label class="switch"> makes the whole 44px row the target.
  4. Description (optional).check__description under the label, 14px muted.
  5. State text (optional).switch__state "On" / "Off", 14px muted, aria-hidden because the switch already reports its state.

Variants

Label after the switch (default)

For short lists of settings in a form column. The control lines up at the start edge.

Label before the switch

For settings lists and panels: labels at the start, switches aligned at the end edge so their states read as a column..switch--end

With description and state text

The description explains the effect. Visible "On" / "Off" helps people who do not read the track position; it is hidden from assistive technology to avoid double announcements.

Sizes

One size. The 44 × 24px track sits in a 44px row (--control-height-md); a smaller track would make the thumb position hard to read and a larger one adds nothing.

States

Focus is forced with data-state="focus". The switch has no separate hover or pressed paint: the whole row shows a pointer cursor and the thumb moves on release, so the hover and active columns match the default.

Disabled with a reason

Disabled: dashed track edge, readable --color-fg-disabled label. Always say why.

Both themes

  • On: accent track, light thumb at the end. Off: surface track, strong-border thumb at the start. Position, not colour, carries the state.
  • Busy: when a change must reach a server, apply it optimistically and announce "Reminders turned on." in a status region; if it fails, flip it back and show an inline message. Never leave a switch in a half state.
  • Invalid does not apply: a switch always holds a valid value. If one position is required, it is not a setting; use a checkbox in a form.

Responsive behaviour

  • The row is at least 44px tall at every width. Labels wrap beside the track; the track never shrinks (flex: none).
  • .switch--end rows stretch to their container, so in a narrow panel the switch stays at the end edge and a long label wraps over several lines. Give such rows the full column width so the switches align.
  • At 200% text or with text-spacing overrides the label grows and wraps; the track keeps its size and stays vertically centred on the row.
  • Right-to-left: .switch--end mirrors with the row. The thumb is positioned from the physical left, so in RTL "on" still sits on the right; mirror the thumb before shipping an RTL settings page.

Theming

The switch declares two component tokens on its input: --switch-track (--color-bg-surface off, --color-accent on) and --switch-thumb (--color-border-strong off, --color-fg-on-accent on). The edge reads --color-border-strong, then --color-accent when on. In the dark theme the on track is teal-300 with a sage-900 thumb.

/* Re-skin the on state inside a host area */
.learner-portal .switch input:checked { --switch-track: var(--color-success-solid); border-color: var(--color-success-solid); }

In forced-colours mode the custom track is replaced by system colours; the thumb position still shows the state. See theming.

Accessibility

Role and pattern

A native checkbox with role="switch", styled with appearance: none, following the WAI-ARIA APG Switch pattern. Screen readers announce "Email reminders, switch, on". The checked state comes from the native checked property, so no aria-checked is needed.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the switch. Each switch is its own Tab stop.
SpaceToggles on and off.
EnterDoes not toggle (native checkbox behaviour; the APG makes Enter optional). Do not add Enter handling, so the switch behaves like every other native checkbox.

Focus

The shared 3px amber ring with 2px offset surrounds the track on :focus-visible. Focus stays on the switch after toggling.

Labelling

The wrapping label names the setting, not the action: "Email reminders", not "Turn on email reminders", because the state is announced separately. Descriptions are linked with aria-describedby. Visible "On" / "Off" text is aria-hidden. When a change affects other people (all learners in a course), confirm it in a polite status region.

Motion

The thumb slides and the track colour changes over --duration-fast (150 ms). Under prefers-reduced-motion the duration is zeroed and the thumb jumps.

Touch

The whole 44px label row is the target. Stacked switches have no gap but each row is 44px; tapping anywhere on a row toggles only that switch. There is no drag gesture to learn: a tap toggles.

Content

  • Name the setting as a noun phrase in sentence case: "Email reminders", "Quiz retakes", "Transcript beside the video".
  • Make "on" mean the feature is active. Avoid negatives such as "Disable reminders"; an on switch that turns something off confuses everyone.
  • Use the description for the effect and its scope: "Remind learners 3 days before the due date."
  • State text is "On" / "Off" only; never "Yes" / "No" or "Enabled" / "Disabled".
  • Disabled switches say why: "This course has no quiz."
