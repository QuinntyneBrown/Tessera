Workplace safety essentials

Required learning · 35 minutes

    Select at least one learner.

    Select one or more learners. Search to narrow the results.

    Try the interaction

    • Search “Morgan” or “Alex”, or open the list to browse everyone.
    • Use ↑ / ↓ or Page Up / Page Down to browse, then Enter or Space to select. Selected learners stay in the results.
    • Escape closes the list. Tab continues through the form.
    • With an empty search, Backspace removes the last selection. Use ← to reach its remove button.
    • Scroll to the bottom or use Load more for more results. Use the preview controls to explore failure and edge states, the dark theme, and custom templates.

    Mock configuration: 300 ms debounce, empty-query browsing enabled. No production Angular API is implemented here.
